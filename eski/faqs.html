Is Mailmyra working without a backend right now?

Yes. The current version is a frontend demo. Users can enter details and preview changes; exporting HTML is routed through login and yearly plan activation.

How does the generated signature get used?

The generator prepares signature HTML that can be copied and later installed in email clients or connected to a backend flow.

Can I use my own logo and profile photo?

Yes. Hosted image URLs can be added for profile photo, company logo and handwritten signature visuals.

Do templates really change the preview layout?

Yes. Template choices update the signature preview with class-based layout variations while preserving entered data.

Can the signature match Mailmyra brand colors?

Yes. The default visual system uses Mailmyra blue, warm sand and neutral gray, with controls for theme, text and link colors.

Can I add a CTA button?

Yes. The Styles step includes CTA type, text and URL fields so the preview can display a small branded call to action.

Are pricing plans connected to real billing?

No. The checkout is a frontend simulation, but the flow now behaves like a yearly subscription gate for export and dashboard access.

Which plan is best for teams?

The Business direction is best for teams that need shared brand standards, campaign CTAs and a repeatable signature system.
